# 🧮 Scientific Computing Suite

A modular Python-based scientific computing application for solving equations,
numerical analysis, plotting, and data visualization.

## ✨ Features

- **Equation Solver** — Symbolic (SymPy) and numerical (SciPy) solving
- **Calculus** — Integration, differentiation, ODEs, series expansion
- **Plotting** — 2D/3D graphs, contour plots, vector fields, network graphs
- **GUI & CLI** — Both interfaces available
- **Plugins** — Statistics and signal processing
- **Docker Support** — Reproducible environment

## 🚀 Quick Start

### Using Docker (Recommended)

```bash
# Build image
docker-compose build

# Run CLI
./run.sh cli

# Run GUI (Linux/Mac)
./run.sh gui
```
